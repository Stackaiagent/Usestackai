# What is StackAI

StackAI is an **AI agent** you run where you already work. It started as a coding agent for your terminal and grew into a general agent that loads **skills** to do real tasks — read and write code, run commands, and pull live on-chain data.

It's powered by **Xiaomi MiMo v2.5 Pro** (1M token context) by default, and you can switch to other models like Venice.

## Who it's for

* **Developers** who want an AI that edits real files and runs real commands in their project, from the terminal.
* **Crypto users** who want token reports, rug checks, market data, and Bankr trading — by chat, on the CLI or Telegram.
* **Anyone** who'd rather describe a task in plain language than click through tools.

## Three surfaces, one agent

| Surface | Best for |
|---|---|
| **CLI** (`stackai`) | Full coding agent + every skill. Trading and token launches live here (your keys stay on your machine). |
| **Web** ([Vibe](vibe.md)) | Build a project by chatting and download the `.zip`. |
| **Telegram** ([@StackAIagent_bot](telegram.md)) | Read-only crypto skills on the go — token reports, rug checks, trending, Bankr launches. |

All three run the **same engine** and the **same skills**. The only difference is the door you walk in through.

## What makes it different

* **It does real work.** The agent reads and writes the actual files in your project and runs commands you approve — it's not a chat window you copy-paste out of.
* **Skills, not hard-coding.** A [skill](skills.md) is a small runbook the agent loads when it's relevant. New skills don't require a new release — you can [install them](installing-skills.md) from any GitHub repo.
* **You stay in control.** Bring your own keys (Venice, Bankr). Your trading key never leaves your machine. Every command needs your approval. The whole thing is open source.
