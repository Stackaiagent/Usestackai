# Welcome to StackAI

StackAI is an AI agent you run where you work. Tell it what you want — it reads your files, runs commands you approve, writes code, and pulls live on-chain data through **skills**. Use it in your terminal, on the web ([Vibe](vibe.md)), or on [Telegram](telegram.md).

```bash
npm install -g stackai
stackai login
stackai
```

### What makes it different

* **It does real work** — reads and writes the actual files in your project and runs commands you approve.
* **Skills, not hard-coding** — load a [skill](skills.md) for a task, or [install more](installing-skills.md) from any GitHub repo.
* **Multi-surface** — the same agent in your terminal, on the web, and on Telegram.
* **You stay in control** — bring your own model/keys ([Venice](models.md), [Bankr](bankr.md)); your trading key never leaves your machine.
* Powered by **Xiaomi MiMo v2.5 Pro** with a **1M token** context window.
